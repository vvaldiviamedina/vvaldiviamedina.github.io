El cuidado remunerado, en otros formatos

Los mismos datos de segregación de género en el cuidado — cinco formas alternativas de leerlos, pensadas para comparar países más adelante

La página Cuidado remunerado muestra estos datos con barras verticales y un facet por definición. Aquí exploramos cinco formas distintas de mirar exactamente la misma información — todas horizontales, para que las dos dimensiones del dato (definiciones anidadas y categorías individuales) compartan un mismo eje y se puedan comparar directamente entre sí.

El selector de país de abajo hoy solo tiene Chile, pero el gráfico está armado para que agregar otro país sea solo agregar filas con un campo country distinto — no un rediseño.

NoteFuente de los datos

Clasificación por ocupación (CIUO-08, 2 dígitos) y rama (CAENES, 1 dígito), de la ENUT — los mismos datos que Cuidado remunerado, reestructurados aquí en formato “largo” (una fila por categoría × sexo × país).

ImportantUn detalle que cambia cómo se leen estos números

share para hombres y share para mujeres no salen del mismo denominador. Vienen de svyby(~indicador, by=~sexo, FUN=svymean), que calcula el promedio dentro de cada sexo por separado: 22,7% quiere decir “22,7% de las mujeres ocupadas”, sobre el total de mujeres ocupadas — no “22,7% de todas las personas ocupadas”. Lo mismo para el 7,3% de hombres, pero sobre el total de hombres ocupados. Son dos tasas de dos poblaciones distintas, no dos pedazos de una misma torta — por eso no se pueden sumar ni combinar en un solo 100%.

function pairRows(data) {
  const byCategory = d3.group(data, d => d.category);
  return Array.from(byCategory, ([category, rows]) => ({
    category,
    shareH: rows.find(r => r.sex === "Hombres")?.share,
    shareM: rows.find(r => r.sex === "Mujeres")?.share
  }));
}
sharedShareMax = Math.ceil(d3.max([...paidCareData, ...cwdData], d => Math.max(d.share, d.ci_high)) * 100 / 5) * 5 / 100
sharedRatioMax = Math.ceil(d3.max([...pairRows(paidCareData), ...pairRows(cwdData)], d => d.shareM / d.shareH))
function groupedBarPanel(data, order, width) {
  return Plot.plot({
    width,
    marginLeft: 240,
    fy: { domain: order, label: null },
    y: { domain: ["Hombres", "Mujeres"], axis: null },
    x: { domain: [0, sharedShareMax], grid: true, label: "Proporción de personas ocupadas →", tickFormat: v => Math.round(v * 100) + "%" },
    color: { legend: true, domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.barX(data, { fy: "category", y: "sex", x: "share", fill: "sex", insetTop: 6, insetBottom: 6 }),
      Plot.ruleX(data, { fy: "category", y: "sex", x1: "ci_low", x2: "ci_high", stroke: "#333", strokeWidth: 1.5 }),
      Plot.text(data, { fy: "category", y: "sex", x: "share", dx: 8, textAnchor: "start", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.tip(data, Plot.pointer({
        fy: "category", y: "sex", x: "share",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}% (IC 95%: ${(d.ci_low * 100).toFixed(1)}%–${(d.ci_high * 100).toFixed(1)}%)`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 76 + 40
  });
}

function divergingPanel(data, order, width) {
  const signed = data.map(d => ({ ...d, xval: d.sex === "Hombres" ? -d.share : d.share }));
  return Plot.plot({
    width,
    marginLeft: 240,
    y: { domain: order, label: null },
    x: { domain: [-sharedShareMax, sharedShareMax], grid: true, label: "← Hombres      Mujeres →", tickFormat: v => Math.abs(Math.round(v * 100)) + "%" },
    color: { legend: true, domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.barX(signed, { y: "category", x: "xval", fill: "sex", insetTop: 6, insetBottom: 6 }),
      Plot.text(signed.filter(d => d.sex === "Hombres"), { y: "category", x: "xval", dx: -8, textAnchor: "end", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.text(signed.filter(d => d.sex === "Mujeres"), { y: "category", x: "xval", dx: 8, textAnchor: "start", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.tip(signed, Plot.pointer({
        y: "category", x: "xval",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}%`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 60 + 40
  });
}

function ratioPanel(data, order, width) {
  const rows = pairRows(data).map(r => ({ ...r, ratio: r.shareM / r.shareH }));
  return Plot.plot({
    width,
    marginLeft: 240,
    y: { domain: order, label: null },
    x: { domain: [0, sharedRatioMax], grid: true, label: "Mujeres, veces más probable que hombres →" },
    marks: [
      Plot.barX(rows, { y: "category", x: "ratio", fill: accentColor, insetTop: 10, insetBottom: 10 }),
      Plot.text(rows, { y: "category", x: "ratio", dx: 8, textAnchor: "start", text: d => d.ratio.toFixed(1) + "×", fill: "currentColor", fontWeight: 700 }),
      Plot.ruleX([1], { stroke: "#333", strokeWidth: 1.5, strokeDasharray: "4,3" }),
      Plot.text([{ x: 1, label: "paridad (1×)" }], { x: "x", y: order[order.length - 1], dy: 28, text: "label", fill: "currentColor", fontSize: 10, textAnchor: "middle" }),
      Plot.tip(rows, Plot.pointer({
        y: "category", x: "ratio",
        title: d => `${d.category}\nMujeres: ${(d.shareM * 100).toFixed(1)}% · Hombres: ${(d.shareH * 100).toFixed(1)}%\n${d.ratio.toFixed(2)}× más mujeres que hombres`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 60 + 60
  });
}

function heatmapPanel(data, order, width) {
  return Plot.plot({
    width,
    marginLeft: 240,
    marginRight: 40,
    y: { domain: order, label: null },
    x: { domain: ["Hombres", "Mujeres"], label: null },
    color: { domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.cell(data, { y: "category", x: "sex", fill: "sex", fillOpacity: d => 0.25 + 0.75 * (d.share / sharedShareMax), inset: 3 }),
      Plot.text(data, {
        y: "category", x: "sex", fontWeight: 700,
        text: d => (d.share * 100).toFixed(1) + "%",
        fill: d => d.share / sharedShareMax > 0.5 ? "white" : "currentColor"
      }),
      Plot.tip(data, Plot.pointer({
        y: "category", x: "sex",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}% (IC 95%: ${(d.ci_low * 100).toFixed(1)}%–${(d.ci_high * 100).toFixed(1)}%)`
      }))
    ],
    height: order.length * 60 + 20
  });
}

// share for each sex has its OWN denominator (see the callout above --
// svyby computes the mean within each sex separately), so a single shared
// 100-square grid mixing both would misrepresent them as slices of one
// population. Instead: two independent 100-square grids per category, one
// for "100 hombres ocupados", one for "100 mujeres ocupadas" -- each
// filled with its own share, in its own color, grey for the rest of that
// same sex's occupied population.
function waffleSquares(share, color) {
  const n = Math.round(share * 100);
  return Array.from({ length: 100 }, (_, i) => ({
    col: i % 10,
    row: Math.floor(i / 10),
    fill: i < n ? color : "#e2e2e2",
    filled: i < n
  }));
}

function waffleGrid(share, color, sexLabel, category) {
  const cell = 10, gap = 2, side = cell * 10 + gap * 9;
  const squares = waffleSquares(share, color);
  const svg = d3.create("svg").attr("width", side).attr("height", side);
  svg.selectAll("rect").data(squares).join("rect")
    .attr("x", d => d.col * (cell + gap))
    .attr("y", d => d.row * (cell + gap))
    .attr("width", cell).attr("height", cell)
    .attr("rx", 2)
    .attr("fill", d => d.fill)
    .append("title").text(d => `${category}\n${d.filled ? sexLabel : `resto de ${sexLabel.toLowerCase()} ocupados/as`}`);
  return svg.node();
}

function wafflePanel(data, order) {
  const legend = html`<div style="display:flex; gap:16px; margin-bottom:16px; font-size:12px; align-items:center; flex-wrap:wrap;"></div>`;
  [["Hombres", colorH], ["Mujeres", colorM], ["Resto de ocupados/as del mismo sexo", "#e2e2e2"]].forEach(([label, color]) => {
    const item = html`<div style="display:flex; align-items:center; gap:6px;"></div>`;
    item.appendChild(html`<span style="display:inline-block; width:12px; height:12px; border-radius:2px; background:${color};"></span>`);
    item.appendChild(html`<span>${label}</span>`);
    legend.appendChild(item);
  });

  const grid = html`<div style="display:flex; flex-wrap:wrap; gap:28px;"></div>`;
  order.forEach(category => {
    const shareH = data.find(d => d.category === category && d.sex === "Hombres")?.share ?? 0;
    const shareM = data.find(d => d.category === category && d.sex === "Mujeres")?.share ?? 0;

    const pair = html`<div style="display:flex; gap:10px;"></div>`;
    const hCol = html`<div style="display:flex; flex-direction:column; align-items:center; gap:4px;"></div>`;
    hCol.appendChild(waffleGrid(shareH, colorH, "Hombres", category));
    hCol.appendChild(html`<div style="font-size:11px;">${(shareH * 100).toFixed(1)}% H</div>`);
    const mCol = html`<div style="display:flex; flex-direction:column; align-items:center; gap:4px;"></div>`;
    mCol.appendChild(waffleGrid(shareM, colorM, "Mujeres", category));
    mCol.appendChild(html`<div style="font-size:11px;">${(shareM * 100).toFixed(1)}% M</div>`);
    pair.appendChild(hCol);
    pair.appendChild(mCol);

    const col = html`<div style="display:flex; flex-direction:column; align-items:center; gap:8px; max-width:280px;"></div>`;
    col.appendChild(pair);
    col.appendChild(html`<div style="font-size:12px; text-align:center;">${category}</div>`);
    grid.appendChild(col);
  });

  const wrapper = html`<div></div>`;
  wrapper.appendChild(legend);
  wrapper.appendChild(grid);
  return wrapper;
}

function panel(data, order, width) {
  if (chartStyle === "Barras divergentes") return divergingPanel(data, order, width);
  if (chartStyle === "Razón mujeres/hombres") return ratioPanel(data, order, width);
  if (chartStyle === "Mapa de calor") return heatmapPanel(data, order, width);
  if (chartStyle === "Waffle") return wafflePanel(data, order);
  return groupedBarPanel(data, order, width);
}

sideBySidePanels = {
  const gap = 28;
  // Quarto's content column width -- fall back progressively if the class
  // name ever changes, so this degrades gracefully instead of breaking.
  const mainEl = document.querySelector("#quarto-document-content") || document.querySelector("main.content") || document.body;
  const totalWidth = mainEl.clientWidth || 900;
  const twoUp = totalWidth >= 900;
  const panelWidth = twoUp ? Math.floor((totalWidth - gap) / 2) : totalWidth;

  const wrapper = html`<div style="display:flex; gap:${gap}px; flex-wrap:wrap; align-items:flex-start;"></div>`;

  col1.appendChild(panel(paidCareData, paidCareOrder, panelWidth));

  const col2 = html`<div style="flex:1 1 ${panelWidth}px; min-width:0;"></div>`;

  col2.appendChild(panel(cwdData, cwdOrder, panelWidth));

  wrapper.appendChild(col1);
  wrapper.appendChild(col2);
  return wrapper;
}
Important

Las cinco vistas muestran exactamente el mismo par de números por categoría (proporción de hombres, proporción de mujeres) — cambia solo qué relación entre esos dos números queda más visible. “Barras agrupadas” y “Barras divergentes” comparan las proporciones directamente; “Razón mujeres/hombres” muestra cuántas veces más frecuente es una que la otra; “Mapa de calor” prioriza compacidad sobre precisión; “Waffle” es la única que ubica cada proporción dentro de su propia población de referencia — 100 hombres ocupados, 100 mujeres ocupadas — en vez de solo comparar los dos números entre sí.

NoteSobre “Razón mujeres/hombres”

Esta vista divide la proporción de mujeres por la de hombres en cada categoría — por eso “Habilitadores” se ve tan alto (14,8×): no es que las mujeres dominen mucho más ahí que en el resto, es que la proporción de hombres es muy baja (0,4%) y casi cualquier número dividido por un valor tan pequeño da una razón grande. Las razones calculadas sobre denominadores chicos son ruidosas — hay que leerlas con más cautela que las proporciones de las que salen. Por eso esta vista no reemplaza a “Barras agrupadas”: la complementa.

Cómo se hizo esta página

  1. Reutiliza exactamente los mismos dos archivos JSON que Cuidado remunerado (paid_care_workforce_by_sex.json, paid_care_workforce_cwd_by_sex.json) — ningún dato nuevo, solo una reestructuración a formato largo y cinco formas de graficarlo.
  2. Diseño pensado para más países: cada fila del dato lleva un campo country (hoy solo "Chile"). El selector de país se arma dinámicamente con [...new Set(allLong.map(d => d.country))], así que agregar Argentina, México, etc. — con su propio paid_care_workforce_by_sex.json reetiquetado por país — haría aparecer la opción en el selector sin tocar el código del gráfico.
  3. Eje compartido de verdad: los dos paneles (definiciones anidadas / categorías individuales) se dibujan como gráficos Observable Plot separados, pero sharedShareMax y sharedRatioMax se calculan una sola vez a partir de ambos conjuntos de datos juntos, y ambos paneles reciben ese mismo número como dominio de su eje — así quedan realmente a la misma escala, no solo visualmente parecidos. Los dos paneles también se ubican lado a lado en vez de uno arriba del otro, midiendo el ancho real de la columna de contenido (document.querySelector("#quarto-document-content").clientWidth) y pasándole la mitad a cada gráfico de Plot — usa todo el ancho disponible en vez de dejarse en los 640px por defecto de Plot. En pantallas angostas (menos de 900px) vuelve a apilarlos uno sobre otro, para no aplastar las etiquetas de categoría.
  4. La primera versión de esta página usaba un gráfico de puntos con brecha (dumbbell) para comparar hombres y mujeres. Se reemplazó por barras agrupadas: un dumbbell da a entender un cambio entre dos momentos o estados de la misma cosa (antes/después), y aquí no hay ninguna secuencia — son dos grupos distintos medidos en el mismo momento. Barras agrupadas no sugiere esa lectura y sigue permitiendo el intervalo de confianza como un trazo sobre cada barra.
  5. “Mapa de calor” mantiene el color por sexo (verde/morado) en vez de una escala secuencial de un solo tono, para no romper la convención de color del resto del sitio — la magnitud se codifica con la opacidad, no con el matiz.
  6. “Waffle” pasó por dos versiones. La primera dibujaba un solo cuadriculado de 100 casillas por categoría, con casillas de hombres y de mujeres en el mismo grupo de 100 — como si ambos porcentajes salieran de la misma población total de personas ocupadas. No es así: share se calcula por separado dentro de cada sexo (svyby(~indicador, by=~sexo, FUN=svymean)), así que 22,7% de mujeres y 7,3% de hombres son tasas de dos poblaciones distintas, no dos pedazos de un mismo 100%. La versión actual dibuja dos cuadriculados de 100 por categoría — “100 hombres ocupados” y “100 mujeres ocupadas”, cada uno con su propio color y su propio gris — para no implicar una suma que los datos no permiten.
  7. “Composición por sexo” (100% apiladas) tenía el mismo problema desde el principio — calculaba shareH / (shareH + shareM) como si esa suma fuera un total real. Como no tenemos los denominadores poblacionales de hombres y mujeres ocupados por separado (solo sus tasas internas), no hay forma de calcular esa composición correctamente con los datos disponibles, así que se sacó de la lista en vez de dejarla con un cálculo que no se sostiene.
  8. El resto del sitio (incluidos los scripts de procesamiento de datos) usa R, y R tiene un paquete de verdad para hacer waffles (geom_waffle()), pero como esta página se renderiza entera en el navegador sin backend — igual que todas las demás — el waffle se dibuja con D3 directamente, no con una imagen pre-generada en R.
