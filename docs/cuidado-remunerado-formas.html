El cuidado remunerado, en otros formatos

Los mismos datos de segregación de género en el cuidado — cinco formas alternativas de leerlos, pensadas para comparar países más adelante

La página Cuidado remunerado muestra estos datos con barras verticales y un facet por definición. Aquí exploramos cinco formas distintas de mirar exactamente la misma información — todas horizontales, para que las dos dimensiones del dato (definiciones anidadas y categorías individuales) compartan un mismo eje y se puedan comparar directamente entre sí.

El selector de país de abajo hoy solo tiene Chile, pero el gráfico está armado para que agregar otro país sea solo agregar filas con un campo country distinto — no un rediseño.

NoteFuente de los datos

Clasificación por ocupación (CIUO-08, 2 dígitos) y rama (CAENES, 1 dígito), de la ENUT — los mismos datos que Cuidado remunerado, reestructurados aquí en formato “largo” (una fila por categoría × sexo × país).

colorH = "#5c9e95"
colorM = "#c7a3c0"
accentColor = "#c26b5a"
paidCareRaw = FileAttachment("data/enut/paid_care_workforce_by_sex.json").json()
cwdRaw = FileAttachment("data/enut/paid_care_workforce_cwd_by_sex.json").json()
paidCareOrder = ["Trabajo de cuidados remunerados", "TCR + Habilitadores", "TCR + Habilitadores + Facilitadores"]
cwdOrder = ["TCR dentro del sector", "TCR fuera del sector", "Habilitadores", "Facilitadores"]
allLong = [
  ...paidCareRaw.map(d => ({ ...d, category: d.definition, group: "paidCare", country: "Chile" })),
  ...cwdRaw.map(d => ({ ...d, category: d.definition, group: "cwd", country: "Chile" }))
]
countries = [...new Set(allLong.map(d => d.country))]
viewof selectedCountry = Inputs.select(countries, { label: "País", value: "Chile" })
viewof chartStyle = Inputs.radio(
  ["Barras agrupadas", "Barras divergentes", "Razón mujeres/hombres", "Composición por sexo", "Mapa de calor"],
  { label: "Estilo de gráfico", value: "Barras agrupadas" }
)
paidCareData = allLong.filter(d => d.group === "paidCare" && d.country === selectedCountry)
cwdData = allLong.filter(d => d.group === "cwd" && d.country === selectedCountry)
function pairRows(data) {
  const byCategory = d3.group(data, d => d.category);
  return Array.from(byCategory, ([category, rows]) => ({
    category,
    shareH: rows.find(r => r.sex === "Hombres")?.share,
    shareM: rows.find(r => r.sex === "Mujeres")?.share
  }));
}
sharedShareMax = Math.ceil(d3.max([...paidCareData, ...cwdData], d => Math.max(d.share, d.ci_high)) * 100 / 5) * 5 / 100
sharedRatioMax = Math.ceil(d3.max([...pairRows(paidCareData), ...pairRows(cwdData)], d => d.shareM / d.shareH))
function groupedBarPanel(data, order) {
  return Plot.plot({
    marginLeft: 240,
    fy: { domain: order, label: null },
    y: { domain: ["Hombres", "Mujeres"], axis: null },
    x: { domain: [0, sharedShareMax], grid: true, label: "Proporción de personas ocupadas →", tickFormat: v => Math.round(v * 100) + "%" },
    color: { legend: true, domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.barX(data, { fy: "category", y: "sex", x: "share", fill: "sex", insetTop: 6, insetBottom: 6 }),
      Plot.ruleX(data, { fy: "category", y: "sex", x1: "ci_low", x2: "ci_high", stroke: "#333", strokeWidth: 1.5 }),
      Plot.text(data, { fy: "category", y: "sex", x: "share", dx: 8, textAnchor: "start", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.tip(data, Plot.pointer({
        fy: "category", y: "sex", x: "share",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}% (IC 95%: ${(d.ci_low * 100).toFixed(1)}%–${(d.ci_high * 100).toFixed(1)}%)`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 76 + 40
  });
}

function divergingPanel(data, order) {
  const signed = data.map(d => ({ ...d, xval: d.sex === "Hombres" ? -d.share : d.share }));
  return Plot.plot({
    marginLeft: 240,
    y: { domain: order, label: null },
    x: { domain: [-sharedShareMax, sharedShareMax], grid: true, label: "← Hombres      Mujeres →", tickFormat: v => Math.abs(Math.round(v * 100)) + "%" },
    color: { legend: true, domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.barX(signed, { y: "category", x: "xval", fill: "sex", insetTop: 6, insetBottom: 6 }),
      Plot.text(signed.filter(d => d.sex === "Hombres"), { y: "category", x: "xval", dx: -8, textAnchor: "end", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.text(signed.filter(d => d.sex === "Mujeres"), { y: "category", x: "xval", dx: 8, textAnchor: "start", text: d => (d.share * 100).toFixed(1) + "%", fill: "currentColor", fontWeight: 700, fontSize: 11 }),
      Plot.tip(signed, Plot.pointer({
        y: "category", x: "xval",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}%`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 60 + 40
  });
}

function ratioPanel(data, order) {
  const rows = pairRows(data).map(r => ({ ...r, ratio: r.shareM / r.shareH }));
  return Plot.plot({
    marginLeft: 240,
    y: { domain: order, label: null },
    x: { domain: [0, sharedRatioMax], grid: true, label: "Mujeres, veces más probable que hombres →" },
    marks: [
      Plot.barX(rows, { y: "category", x: "ratio", fill: accentColor, insetTop: 10, insetBottom: 10 }),
      Plot.text(rows, { y: "category", x: "ratio", dx: 8, textAnchor: "start", text: d => d.ratio.toFixed(1) + "×", fill: "currentColor", fontWeight: 700 }),
      Plot.ruleX([1], { stroke: "#333", strokeWidth: 1.5, strokeDasharray: "4,3" }),
      Plot.text([{ x: 1, label: "paridad (1×)" }], { x: "x", y: order[order.length - 1], dy: 28, text: "label", fill: "currentColor", fontSize: 10, textAnchor: "middle" }),
      Plot.tip(rows, Plot.pointer({
        y: "category", x: "ratio",
        title: d => `${d.category}\nMujeres: ${(d.shareM * 100).toFixed(1)}% · Hombres: ${(d.shareH * 100).toFixed(1)}%\n${d.ratio.toFixed(2)}× más mujeres que hombres`
      })),
      Plot.ruleX([0])
    ],
    height: order.length * 60 + 60
  });
}

function compositionPanel(data, order) {
  const rows = pairRows(data).flatMap(r => {
    const total = r.shareH + r.shareM;
    return [
      { category: r.category, sex: "Hombres", comp: r.shareH / total },
      { category: r.category, sex: "Mujeres", comp: r.shareM / total }
    ];
  });
  return Plot.plot({
    marginLeft: 240,
    y: { domain: order, label: null },
    x: { domain: [0, 1], grid: true, label: "Composición por sexo dentro de la categoría →", tickFormat: v => Math.round(v * 100) + "%" },
    color: { legend: true, domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.barX(rows, { y: "category", x: "comp", fill: "sex" }),
      Plot.tip(rows, Plot.pointer({
        y: "category", x: "comp",
        title: d => `${d.category}\n${d.sex}: ${(d.comp * 100).toFixed(1)}% de quienes trabajan en esta categoría`
      })),
      Plot.ruleX([0, 1])
    ],
    height: order.length * 50 + 40
  });
}

function heatmapPanel(data, order) {
  return Plot.plot({
    marginLeft: 240,
    marginRight: 40,
    y: { domain: order, label: null },
    x: { domain: ["Hombres", "Mujeres"], label: null },
    color: { domain: ["Hombres", "Mujeres"], range: [colorH, colorM] },
    marks: [
      Plot.cell(data, { y: "category", x: "sex", fill: "sex", fillOpacity: d => 0.25 + 0.75 * (d.share / sharedShareMax), inset: 3 }),
      Plot.text(data, {
        y: "category", x: "sex", fontWeight: 700,
        text: d => (d.share * 100).toFixed(1) + "%",
        fill: d => d.share / sharedShareMax > 0.5 ? "white" : "currentColor"
      }),
      Plot.tip(data, Plot.pointer({
        y: "category", x: "sex",
        title: d => `${d.category}\n${d.sex}\n${(d.share * 100).toFixed(1)}% (IC 95%: ${(d.ci_low * 100).toFixed(1)}%–${(d.ci_high * 100).toFixed(1)}%)`
      }))
    ],
    height: order.length * 60 + 20
  });
}

function panel(data, order) {
  if (chartStyle === "Barras divergentes") return divergingPanel(data, order);
  if (chartStyle === "Razón mujeres/hombres") return ratioPanel(data, order);
  if (chartStyle === "Composición por sexo") return compositionPanel(data, order);
  if (chartStyle === "Mapa de calor") return heatmapPanel(data, order);
  return groupedBarPanel(data, order);
}

Categorías individuales del ecosistema de cuidados

panel(cwdData, cwdOrder)
Important

Las cinco vistas muestran exactamente el mismo par de números por categoría (proporción de hombres, proporción de mujeres) — cambia solo qué relación entre esos dos números queda más visible. “Barras agrupadas” y “Barras divergentes” comparan las proporciones directamente; “Razón mujeres/hombres” y “Composición por sexo” muestran, cada una a su manera, cuántas veces más frecuente es una que la otra; “Mapa de calor” prioriza compacidad sobre precisión.

NoteSobre “Razón mujeres/hombres”

Esta vista divide la proporción de mujeres por la de hombres en cada categoría — por eso “Habilitadores” se ve tan alto (14,8×): no es que las mujeres dominen mucho más ahí que en el resto, es que la proporción de hombres es muy baja (0,4%) y casi cualquier número dividido por un valor tan pequeño da una razón grande. Las razones calculadas sobre denominadores chicos son ruidosas — hay que leerlas con más cautela que las proporciones de las que salen. Por eso esta vista no reemplaza a “Barras agrupadas”: la complementa.

Cómo se hizo esta página

  1. Reutiliza exactamente los mismos dos archivos JSON que Cuidado remunerado (paid_care_workforce_by_sex.json, paid_care_workforce_cwd_by_sex.json) — ningún dato nuevo, solo una reestructuración a formato largo y cinco formas de graficarlo.
  2. Diseño pensado para más países: cada fila del dato lleva un campo country (hoy solo "Chile"). El selector de país se arma dinámicamente con [...new Set(allLong.map(d => d.country))], así que agregar Argentina, México, etc. — con su propio paid_care_workforce_by_sex.json reetiquetado por país — haría aparecer la opción en el selector sin tocar el código del gráfico.
  3. Eje compartido de verdad: los dos paneles (definiciones anidadas / categorías individuales) se dibujan como gráficos Observable Plot separados, pero sharedShareMax y sharedRatioMax se calculan una sola vez a partir de ambos conjuntos de datos juntos, y ambos paneles reciben ese mismo número como dominio de su eje — así quedan realmente a la misma escala, no solo visualmente parecidos.
  4. La primera versión de esta página usaba un gráfico de puntos con brecha (dumbbell) para comparar hombres y mujeres. Se reemplazó por barras agrupadas: un dumbbell da a entender un cambio entre dos momentos o estados de la misma cosa (antes/después), y aquí no hay ninguna secuencia — son dos grupos distintos medidos en el mismo momento. Barras agrupadas no sugiere esa lectura y sigue permitiendo el intervalo de confianza como un trazo sobre cada barra.
  5. “Mapa de calor” mantiene el color por sexo (verde/morado) en vez de una escala secuencial de un solo tono, para no romper la convención de color del resto del sitio — la magnitud se codifica con la opacidad, no con el matiz.
